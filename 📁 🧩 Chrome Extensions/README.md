## 🚀 त्वरित शुरुआत (Quick Start - Test in Chrome)

1. अपने Google Chrome ब्राउज़र में जाएं: `chrome://extensions/`
2. ऊपर दाईं ओर **Developer mode** को **ON** करें।
3. **Load unpacked** पर क्लिक करें।
4. `📁 🚀 Smart_Styler_Word_Counter_Demo` फ़ोल्डर को चुनें।
5. आपका एक्सटेंशन टूलबार में तैयार है!
