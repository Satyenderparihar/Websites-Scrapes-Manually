## 🚀 2-Step Viral Workflow (1-Click Copy Prompts)

---

### 🔹 Step 1: Reference Photo Ka JSON Design Nikalein

1. Pinterest ya web se apni pasand ki koi bhi aesthetic photo save karein:

![Download Reference Image](🖼️%20Face_Consistency_Screenshots/01_Reference_Image_Pinterest.jpg)

2. ChatGPT me wo photo upload karein aur ye prompt likhein:

![ChatGPT JSON Prompt](🖼️%20Face_Consistency_Screenshots/02_ChatGPT_JSON_Prompt.jpg)

#### 📋 Copy Prompt 1:
```text
Give the json design of this image
```

3. ChatGPT us photo ka complete JSON code generate kar dega (Lighting, Wardrobe, Pose, Environment):

![ChatGPT JSON Result](🖼️%20Face_Consistency_Screenshots/03_ChatGPT_JSON_Result.jpg)

---

### 🔹 Step 2: Apni Photo Upload Karke Face Consistent Karein

1. ChatGPT me **apna face / selfie photo** upload karein.
2. Ye instruction likhein aur neeche wahi JSON code paste kar dein:

![Upload Face with JSON](🖼️%20Face_Consistency_Screenshots/04_Upload_Face_Instruction.jpg)

#### 📋 Copy Prompt 2:
```text
Modify the above image with below instructions.

[PASTE GENERATED JSON CODE HERE]
```

3. **Final Result**: ChatGPT aapke chehre ko exact usi aesthetic scene, kapdo aur lighting me preserve karke generate kar dega:

![Final Consistent Face Result](🖼️%20Face_Consistency_Screenshots/05_Final_Consistent_Face_Result.jpg)
