## ⚡ Core Features in Detail

- **🤖 Antigravity AI Bridge**: Connects Google Antigravity Coding Agents directly to Google Flow (Veo 3.1 & Imagen 3) via a high-speed 1-click local MCP WebSocket bridge.
- **🎭 Character Consistency Engine**: Automatically generates and waits for 100% complete character reference cards before rendering dependent video scenes.
- **🔒 Universal Reference Lock**: Automatically binds character reference cards (`@character` chips) into every scene prompt without manual clicking.
- **🎬 Scene-to-Scene Continuity**: Grabs the terminal end frame of scene $N$ directly in memory (<30ms) using an HTML5 Canvas pipeline and feeds it as the start frame for scene $N+1$ with zero visual drift.
- **⚡ Rapid Batch Dispatch**: Submits 100+ video prompts automatically in sequence with zero manual button pressing.
- **🚀 Zero-Copy Fast Upload**: Injects reference images and video frames into Google Flow in <440ms directly from RAM via synthetic DataTransfer streams.
- **📱 100% Mobile Ready**: Full support for Android Termux + Antigem + Kiwi Browser with anti-crash and low-memory handling.
- **🔐 Creator Lock Gate**: Automatic unlock via YouTube subscription to [@dipeshkyd](https://youtube.com/@dipeshkyd).

## 🧩 Chrome & Kiwi Browser Setup (Load Unpacked)

1. Open **Google Chrome**, **Brave**, **Edge**, or **Kiwi Browser** (Android).
2. Navigate to: `chrome://extensions`
3. Turn ON **Developer mode** (toggle at top-right corner).
4. Click **Load unpacked**.
5. Select the unpacked extension directory:
   ```text
   📁 🧩 DeepX Chrome Extension
   ```
6. Open [Google Flow](https://flow.google.com) or [Google FX Labs Flow](https://labs.google/fx/tools/flow) and log into your Google Account.
7. Keep the Google Flow browser tab active.
