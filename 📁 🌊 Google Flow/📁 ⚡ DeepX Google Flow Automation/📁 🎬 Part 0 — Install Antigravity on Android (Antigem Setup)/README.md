## 📋 Installation & Setup Commands (1-Click Copy)

### 1. Antigem Android Engine Setup (Termux / Git)
```bash
# Clone the official Antigem repository
git clone https://github.com/Santoshkurmi/antigem.git

# Navigate into the project directory
cd antigem

# Run initial setup script
chmod +x setup.sh
./setup.sh
```
