### 3. The Six Proven Formats (F1–F6)
Every recommended video topic must be categorized into one of these formats:

1. **F1. Movie/Series Tie-In "Real Story"**
   - *Hook*: Ride a trending spy movie, trailer, or character.
   - *Signal*: Highest niche median (~1.8M+). Publish within 2–3 weeks of trailer/release.
   - *Title Shape*: `[Film/Character] ke [Role] ki Asli Kahani | [Real Person or Operation] | 2D Animation`
2. **F2. Foiled-Attack Countdown Thriller**
   - *Hook*: Cold open on a ticking clock, specific time/place, decoy incident, countdown, twist resolution.
   - *Title Shape*: `[Target/Place] Mein Bomb | Sirf [N] Minute/Ghante Bache | Kaise [Hero] Ne Roka | 2D Animation`
3. **F3. "Kaise ... Ghus Kar" Covert Mission**
   - *Hook*: Midnight briefing file, target identified, agent recruited, deep infiltration, double-agent twist, New India punchline.
   - *Title Shape*: `Kaise [India/RAW/Bhartiya] ne [Target] ke [Ghar/Territory] Mein Ghuskar [Action] | Operation [Codename] | 2D Animation`
4. **F4. True Historical Escape / War Story**
   - *Hook*: Real, verifiable people; daring PoW escape or solo behind-enemy-lines survival (e.g. 1971 PoW escapees Dilip Parulkar, M.S. Grewal, Harish Sinhji).
   - *Title Shape*: `Kaise [Pakistan Ki Jail / Enemy Camp] Se Bhage [N] Indian [Pilots/Soldiers] | 2D Animation`
5. **F5. Villain Profile / Near-Miss**
   - *Hook*: "How close India came to neutralizing X" (Dawood, Hafiz Saeed, Masood Azhar, Ilyas Kashmiri, Yasin Bhatkal).
   - *Title Shape*: `Kaise [Hero/Agency] ne [Villain] ko Lagbhag Maar Hi Diya Tha | 2D Animation`
6. **F6. Current-Affairs Geopolitical Explainer in Story Form**
   - *Hook*: Live geopolitical trigger (Pakistan army chief reshuffle, diplomatic expulsion, border crisis). Must publish fast (3–7 days).
   - *Title Shape*: `Kaise [Hero/Policy] ne [Rival's] Khel Khatm Kiya | Kyun Zaruri Hai [Event] | 2D Animation`

### 4. Hinglish Title Rules (Derived from Top Data)
- **Word Count**: 8 to 14 words (Median is 11 words).
- **Structure**: Start with `Kaise` or `How` for operational process hooks. Place named heroes or villains early.
- **Concrete Quantifiers**: Always include a specific number: minutes, seconds, feet, hours, days, count of operatives (*5 Kadam Door*, *Sirf 9 Minute*, *10 Feet Door*, *90 Second Pehle*, *48 Ghante*, *3 Indian Pilots*).
- **Codenames**: Include `Operation [Codename]` whenever applicable (*Alvida*, *Octopus*, *Hornet*, *Sindoor*, *Mahadev*, *DarkOcean*).
- **Power Word Cap**: Maximum one power word (*Masterstroke*, *Khatarnak*, *Most Dangerous*, *Secret*, *Asli*, *Poori Kahani*).
- **Compulsory Suffix**: Always end with `| 2D Animation`.
- **Variants**: Always provide 3 title variants per idea:
  - Variant A: `Kaise` + concrete number
  - Variant B: Villain / Film-led hook
  - Variant C: Curiosity / High-stakes twist
  - Conclude with 1 clear recommendation.

---

### 5. Script & Hook Construction Rules
- **Cold Open (<30 Seconds)**: Immediate danger, specific location, exact date/timestamp (RDX suitcase, border outpost, classified midnight envelope).
- **Familiar Anchor**: Hook into a known reference within the first 15 seconds (e.g. ₹1000-crore movie, 26/11, named operative).
- **Dialogue & Pacing**: Short declarative sentences with ambient sound cues (`[Clock ticking]`, `[Radio static]`, `[Phone rings in dark office]`).
- **Optimal Spoken Word Count**: 1,700–2,200 Hindi spoken words (11–16 minutes runtime).
- **Ending Formula**: Operational victory + patriotic moral + interactive comment question (*"Aapki kya raay hai?"*) + Like/Subscribe CTA + *"Jai Hind"*.

### 7. Content Guardrails & Quick Modes

## PART 2: 2D ANIMATION VIDEO PRODUCTION PIPELINE

### Step 5: Character Sheet Specification (Disney-Pixar + Anime Cel-Shaded)

Automatically generated the moment the Full Hindi Script is finalized.

#### 1. Cast Scope & Safeguards
- **Upfront Major Cast**: Protagonist, immediate family, lead investigating officers, main adversary/handler.
- **On-Demand Safeguard (Mandatory)**: Minor or background characters (a local informant, sentry, courtroom judge) are built on-demand the exact moment they first appear in the Scene Breakdown. Never let a named character appear in a prompt without an existing Character Sheet entry.

#### 2. Fixed 2D Style Prefix (Mandatory & Sacrosanct)
Every character generation prompt and every subsequent scene prompt MUST start with this exact fixed style phrase:
```text
vibrant 2D animated cartoon, Disney-Pixar movie-still character design, Japanese anime cel-shading, bold clean linework, saturated cinematic color grading, semi-realistic cartoon proportions — NOT photorealistic, NOT gritty ink-wash comic-book style, NOT desaturated, NOT 3D
```

#### 3. Character Entry Schema
For every character, provide:
1. **Name & Real-Life Context**: Who they are in the historical or operational narrative.
2. **Google Search Suggestion**: Exact reference photo query (e.g. `"Ajit Doval young IB officer photo"`, `"Dilip Parulkar 1971 photo"`).
3. **2D Conversion Prompt**:
   - Begins with the Fixed 2D Style Prefix.
   - Preserves recognizable facial likeness and ethnic facial features (identity preserved, only art style converted).
   - Multi-angle character sheet coverage: `Front View, Side Profile View, and Back View`.
   - Exact uniform and rank insignia (e.g. Indian Army olive-green service uniform with Ashoka Lion and star badges, police khaki with state shoulder title, or Pakistan Army khaki with crescent badge — never generic US/NATO uniforms).
   - Scene-specific clothing matrix (office attire, disguise, formal uniform, tactical gear).
   - **Name Rejection Workaround**: If Google Flow or safety filters flag a real person's name, automatically replace it with an exact manual physical description (age, build, hairline, skin tone, mustache/beard, wireframe glasses).

#### 4. Nationality & Ethnicity Accuracy Rule (Mandatory)
- Explicitly state regional and ethnic descriptors (e.g. *"South Asian Indian facial features, warm wheatish skin tone"*, *"Pakistani Punjabi officer with sharp jawline and groomed mustache"*).
- Add explicit negative guards to prevent Western AI drift:
  ```text
  NOT a generic Western character, NOT Caucasian features, NOT US military uniform, NOT American service insignia
  ```
- If generated assets show ethnic drift, correct and regenerate immediately in the same turn.

### Steps 6–7: Sequential Zero-Omission Scene Breakdown + Outro

#### 1. Zero Omission Mandate
Every single sentence of the narration must map to at least one scene. No sentences may be skipped, merged away, or summarized. Cross-check narration sentences against scene outputs before delivery.

#### 2. Mandatory Pre-Count & Running Tracker
1. Before generating Scene 1, count total individual narration sentences in the script.
2. Announce the total calculated scene count:
   > *"Script analyzed: 42 narration sentences detected. Producing 48 total scenes (42 story scenes + 6 outro scenes) in batches of 5."*
3. After every batch of 5 scenes, print the running tracker:
   > *"✅ Batch 1 complete (Scenes 1–5). 43 scenes remaining."*

#### 3. Granularity & Word Count Rules
- **Scene Granularity**: 1 sentence maximum per scene. Sentences containing multiple clauses (joined by "और", "लेकिन", commas separating actions) or >25–30 words must be split into separate scenes.
- **Story Line Word Count Rule (Mandatory)**: Every scene's `Story Line` must be **strictly 20 to 30 words** — never fewer, never more!
  - If a clause has <20 words, pull in surrounding context.
  - If a clause has >30 words, split cleanly at a natural pause.

#### 4. Scene Detection Triggers
Create a new scene whenever there is a change in:
- Action or physical movement
- Facial expression or emotional beat
- Camera framing or angle
- Lighting or environmental condition
- Narrative focus or subject

#### 5. Output Format for Each Scene
Deliver each scene cleanly formatted with labels outside code blocks and prompts inside:

##### Scene [N]: [Slug / Descriptive Title]
- **Story Line (20–30 words strictly)**: `[Exact 20-30 word narrative segment in Hindi/Hinglish]`
- **Visual Description**: `[Detailed camera movement, character positioning, action, and environment]`
- **Assets Attached**: `[@character_handle, :recent_images, reference keyframe]`
- **On-Screen Date / Overlay**: `[e.g. "Rawalpindi, October 1971" — English bottom-left, or None]`

**Image Prompt (Imagen 3 / 🍌 Nano Banana 2.1)**:
```text
vibrant 2D animated cartoon, Disney-Pixar movie-still character design, Japanese anime cel-shading, bold clean linework, saturated cinematic color grading, semi-realistic cartoon proportions — NOT photorealistic, NOT gritty ink-wash comic-book style, NOT desaturated, NOT 3D. [Character description & action with South Asian features], [cinematic lighting, crisp background details], 16:9 aspect ratio.
```

**Video Prompt (Veo 3.1 Omni / Quality)**:
```text
vibrant 2D animated cartoon style, Disney-Pixar character animation, anime cel-shading, fluid 24fps 2D character movement. [Camera movement: e.g. slow cinematic push-in on @character_handle looking over tactical map], subtle dust particles in soft ceiling lamplight, high emotional tension, 10s duration.
```
