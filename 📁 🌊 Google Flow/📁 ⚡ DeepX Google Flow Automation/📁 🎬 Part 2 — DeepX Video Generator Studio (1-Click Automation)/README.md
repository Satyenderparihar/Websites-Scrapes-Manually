## 🚀 How to Execute 1-Click Video Generation

### Step 1: Download `deepx-video-studio.zip`
Download the official V2 Studio package from [Google Drive v2](https://drive.google.com/drive/folders/1TAGKtq3xTd24pLmCFJPrstGo5hNxDbNc).

### Step 2: Extract or Load into Antigravity
Place the contents inside your working project directory or load the skills directly into Antigravity's context.

### Step 3: Get Your Free Cartesia API Key ($0 — No Card Needed)
1. Visit [**play.cartesia.ai**](https://play.cartesia.ai) and sign in with Google.
2. Go to **API Keys** and click **+ Create API Key**.
3. Set your key: `export CARTESIA_API_KEY="your_api_key"` (includes 20,000 characters free every month).

### Step 4: Fire the Autopilot Command
In your Antigravity chat, provide your topic or command:
```text
Make a 9:16 vertical high-suspense documentary explainer about Psychology on autopilot using DeepX Studio.
```
Antigravity and DeepX will:
1. Write the high-retention script and storyboard.
2. Generate hyper-realistic voiceover using Cartesia AI.
3. Automatically queue visual assets and video animations in Google Flow with character lock.
4. Assemble and render the final broadcast-ready video.
