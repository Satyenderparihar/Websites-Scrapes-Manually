## 🎯 Core Master UGC Prompt Template (Hindi-First 10s Segments)

### 📋 Ready-to-Copy Master Template:

```text
Creator & Vibe: A [age range, e.g. 22-28 year old] [gender] with a [casual/friendly/energetic] vibe, talking directly to camera in natural Hindi like a real customer.

Segment 1: 0-10s (The Hook & Problem)
• Visual: Handheld selfie angle, [bedroom/kitchen/outdoor], creator looks slightly frustrated or curious.
• Script (Hindi): "Yaar, kya aap bhi [problem] se pareshan ho? Maine sab try kiya par kuch kaam nahi aaya..."

Segment 2: 10-20s (The Discovery & Product Intro)
• Visual: Quick cut to creator holding [Product Name], showing the packaging naturally to the lens.
• Script (Hindi): "Phir mujhe mila ye [Product Name]. Honestly, starting mein mujhe laga ye bhi waisa hi hoga, par listen..."

Segment 3: 20-30s (The Demo/Transformation)
• Visual: Close-up B-roll of product in use (applying/opening/using). Natural lighting, raw texture.
• Script (Hindi): "Isko use karna itna simple hai. Dekho, [action/demo description]. Results sirf [X days] mein dikhne lage!"

Segment 4: 30-40s (Trust & Final Verdict)
• Visual: Back to face-to-camera, creator looks happy/relieved, showing the final result (glowing skin/organized desk).
• Script (Hindi): "Ab meri life [problem] ke bina bahut better hai. Seriously, agar aapne ye try nahi kiya, toh miss kar rahe ho."

Segment 5: 40-50s (The CTA)
• Visual: Creator pointing down to on-screen link/button, text overlay with discount code appears.
• Script (Hindi): "Abhi jaao aur apna pack order karo. Link bio mein hai, aur mera code [Code] use karke extra discount paao!"

Camera: Handheld phone-style shot, slight shake, front camera selfie angle (cut to a quick product close-up shot in the middle).
Style: Raw, authentic, unpolished — NOT cinematic, NOT studio lighting, looks native to TikTok/Instagram Reels feed.
Captions: Bold, punchy on-screen text overlay matching spoken words.
Aspect ratio: 9:16 vertical.
Exclusions: No stock-photo look, no overly perfect skin/lighting, no scripted-sounding tone.
```

## 🪝 Hook Bank (First 2 Seconds Decide Scroll-Stop Rate)

### `Problem Hook`
```text
Okay I need to talk about [problem] because nobody warned me...
```

### `Curiosity Hook`
```text
I wasn't going to post this but...
```

### `Before/After Hook`
```text
POV: you finally found [product] after trying everything else
```

### `Shock/Stat Hook`
```text
This [product] literally changed my [routine/skin/life] in [X days]
```

### `Relatable Hook`
```text
If you also struggle with [problem], stop scrolling
```

## 📽️ 15 UGC Ad Types — Pick Your Angle

| Type | Structure (Hindi 10s Segments) | Best For |
| :--- | :--- | :--- |
| **Problem → Solution** | Pain point → discovery → demo → relief (Hindi focus) | New/unknown products |
| **Unboxing** | "It arrived!" → open → first reaction → try it | Physical/tangible products |
| **Testimonial/Review** | "I've used this for X weeks, here's my honest take" | Trust-building, retargeting |
| **Before & After** | Show old struggle → show product → show new result | Skincare, fitness, home, beauty |
| **Day-in-my-life** | Casual vlog where product appears naturally mid-routine | Lifestyle, wellness, food |
| **Founder Story** | "I made this because I couldn't find..." | D2C brands wanting authenticity |
| **Myth-Busting** | "Everyone thinks X is true, but actually Y" → Demo proof → Result | Challenging common misconceptions or industry lies |
| **Comparison/Vs** | "Why I switched from X to Y" → Comparison points → Final recommendation | Competitor switching |
| **Gift Guide/Seasonality** | "Struggling with gifts? This is the perfect fix" → Show product utility | Occasion-based marketing |
| **How-To Hack** | "Did you know you can do X with Y?" → Pro-tip demo | Versatile products |
| **FOMO/Urgency** | "Sirf aaj ke liye offer / Stock khatam ho raha hai" → Scarcity → Urgent CTA | High conversion campaigns |
| **'Lazy' Solution** | "Mujhe mehnat nahi karni, toh maine ye trick try ki" → Quick hack → Easy result | Quick, relatable lifestyle products |
| **Budget/Savings** | "Mehenge alternative mat lo, ye try karo" → Value comparison → Savings | Value-conscious consumers |
| **FAQ/Objection** | "Mujhse sab puch rahe hain kya ye kaam karta hai?" → Answering doubts → Trust | High-ticket or complex items |
| **ASMR/Sensory** | Focus on sounds (opening/using) → Visual pleasure → Satisfaction | Food, skincare, tech gadgets |

## 💡 Quick Tip on Aspect Ratios

> 💡 Quick Tip on Aspect Ratios:
Platform ke hisaab se aspect ratio badlo — 9:16 Reels / TikTok / YouTube Shorts ke liye, 1:1 Instagram Feed ke liye, aur 16:9 Landscape YouTube ke liye.

## 🛠️ Step-by-Step Production Guide

1. **Product Details Fill**: Product ka naam, category aur core benefit fill karo.
2. **Ad-Type Selection**: Ek ad-type table se choose karo.
3. **Hook Selection**: Hook bank se ek hook uthao aur apne product ke hisaab se tweak karo.
4. **Generate Video**: Poora master prompt fill karke seedha apne AI video tool (Kling, Veo, Sora, CapCut AI) mein paste karo.
5. **A/B Testing**: Same prompt structure rakhkar script/hook change karke multiple variations generate karein.

## ✅ Filled Production Example (GlowDrop Vitamin C Serum)

### 📋 Ready-to-Copy Example Prompt:

```text
Creator: A 24-year-old woman with a chill, relatable vibe, talking to camera like a friend.
Setting: Bedroom, morning light, handheld selfie-style, slightly shaky iPhone footage.
Product: GlowDrop Vitamin C Serum — brightens skin in 2 weeks.
Hook: "Okay I need to talk about my skin because nobody warned me it would look THIS different..."

Script:
"I used to have such dull, tired-looking skin no matter what I tried."
"Then my friend told me about this serum and I was skeptical honestly."
"[cut to close-up of applying serum] Look how it just melts in."
"After 2 weeks — this is legit my skin, no filter."
"Link's in my bio if you wanna try it, use code GLOW10 for 10% off."

Camera: Handheld selfie, one quick cutaway to product close-up.
Style: Raw, natural, phone-shot look, no studio lighting.
Captions: Bold white text matching each line.
Aspect ratio: 9:16.
Exclusions: No cinematic color grading, no perfect studio setup.
```
