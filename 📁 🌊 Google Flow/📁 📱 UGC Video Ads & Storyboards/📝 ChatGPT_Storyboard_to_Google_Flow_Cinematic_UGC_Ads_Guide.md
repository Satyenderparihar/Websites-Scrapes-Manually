## 🛠️ Step 1: ChatGPT Me Storyboard Banayein

1. ChatGPT me dress ki photo upload karein:

![Upload Dress Photo](🖼️%20Video_Screenshots/01_ChatGPT_Upload_Dress.jpg)

2. Ye prompt copy karke paste karein:

![Type Prompt](🖼️%20Video_Screenshots/02_ChatGPT_Prompt_Typed.jpg)

### 📋 Copy Prompt:
```text
Create a story board image for my video edit cuts every second for Photoshop
```

3. ChatGPT ye 10-panel storyboard image generate karega:

![Generated Storyboard](🖼️%20Video_Screenshots/03_ChatGPT_Generated_Storyboard.jpg)

---

## 🌊 Step 2: Google Flow Me Video Banayein

1. Google Flow open karke storyboard image upload karein aur ye prompt paste karein:

![Google Flow Prompt](🖼️%20Video_Screenshots/04_Google_Flow_Upload_And_Prompt.jpg)

### 📋 Copy Prompt:
```text
Create a ugc cinematic video for professional video according to this story board sequence
```

2. Exact ye settings select karein:

![Google Flow Settings](🖼️%20Video_Screenshots/05_Google_Flow_Settings.jpg)

| Setting | Value |
| :--- | :--- |
| **Mode** | `Video` |
| **Model** | `Omni 1.1 Flash` |
| **Aspect Ratio** | `9:16` |
| **Resolution** | `720p` |
| **Duration** | `10s` |
| **Quantity** | `x1` *(16 credits)* |
