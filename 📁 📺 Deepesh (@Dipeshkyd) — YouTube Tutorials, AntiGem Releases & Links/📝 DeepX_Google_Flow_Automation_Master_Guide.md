1. Download the extension ZIP bundle from [Google Drive v1](https://drive.google.com/drive/folders/1Ac1NrxrX5N0YrkyikuQXVhwHVfmPjy-4) and extract it.
2. Open **Google Chrome**, **Brave**, **Edge**, or **Kiwi Browser** (Android).
3. Navigate to: `chrome://extensions`
4. Turn ON **Developer mode** (toggle at top-right corner).
5. Click **Load unpacked** and select the extracted `DeepX Chrome Extension` directory.
6. Open [Google Flow](https://flow.google.com) or [Google FX Labs Flow](https://labs.google/fx/tools/flow) and log into your Google Account.
7. Keep the Google Flow browser tab active.

| Tool Name | Purpose |
| :--- | :--- |
| `deepx_status` | Check bridge connection & Google Flow session |
| `deepx_generate_video` | Submit 5s or 10s video generation prompt |
| `deepx_generate_image` | Generate photorealistic Imagen 3 visuals |
| `deepx_rapid_batch_dispatch` | Submit 100+ prompts in autonomous sequence |
| `deepx_auto_chain_scene` | Grab terminal frame & chain into next scene |
| `deepx_upload_asset` | Zero-copy fast inject image/video into Flow |
| `deepx_attach_library_reference` | Bind `@character` chip to prompt |
| `deepx_attach_references_batch` | Bind up to 5 reference cards in <300ms |
| `deepx_generate_character` | Create consistent multi-angle character card |
| `deepx_list_characters` | List all saved character references in project |
| `deepx_download_media` | Download completed video/image to disk |
| `deepx_rapid_storyboard_autopilot` | Run full storyboard generation end-to-end |
| `deepx_analyze_and_breakdown_script` | Break screenplay down into scene prompts |
| `deepx_eval_script` | Verify continuity and negative prompt rules |
| `deepx_open_new_project` | Create new isolated Google Flow project |
| `deepx_rename_project` | Update project title |
| `deepx_cancel_job` | Abort running generation queue |
